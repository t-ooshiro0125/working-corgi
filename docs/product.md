# Working Corgi

## 目的

自己紹介、制作物、技術記事を公開する個人サイトを作る。軽量で読みやすく、GitHub Pages から静的に配信できることを重視する。

## 初期リリース

- 自己紹介を掲載するトップページ
- 経歴や制作物を補足する About ページ
- 技術記事を一覧・個別ページで読めるブログ
- GitHub や SNS など、外部プロフィールへのリンク

## コンテンツの方針

- 技術記事は、あとから Markdown と Astro Content Collections で管理できる構成にする。
- 日本語を基本とし、多言語化は必要になった時点で設計する。
- 記事のタグ、公開日、概要を用意し、一覧で探しやすくする。

## 今回は作らないこと

- ログインやユーザー管理
- コメント、問い合わせフォーム、データベース
- サーバーサイドでの動的な処理
- 広告、アクセス解析、外部サービス連携

## 将来的な拡張

- 制作物の詳細ページ
- RSS フィード
- サイト内検索
- 多言語対応
- 独自ドメイン
